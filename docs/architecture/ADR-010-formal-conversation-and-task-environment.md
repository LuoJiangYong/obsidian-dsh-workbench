# ADR-010：正式会话页与原生任务环境

- 状态：已接受并完成本地实现与远端 CI；Batch 10 专用 Vault 最终验收待完成
- 日期：2026-08-29
- 关联：[ADR-006](./ADR-006-conversation-runtime-storage.md)、[ADR-008](./ADR-008-task-execution-controller.md)、[ADR-009](./ADR-009-task-change-review-and-undo-ui.md)
- UI 审阅真相：Ardot 文件 `718186366720195`、页面 `UI 真相 v2`（`12:1`），产品画板 `12:2`、`12:41`、`12:120`、`12:191`、`12:275`、`12:360` 与 QA `12:530`；Ardot 未修改、只读核对

## 用户结果

首条消息经发送前审阅确认后，同一个 Workbench leaf 从“今天想让 DeepSeek Harness 做什么？”开启页切换为正式会话页。正式页持续显示公开消息、真实状态、权限、工具名称与逐轮文件结果，并保留一个紧凑且可增长的 composer。重复点击 ribbon 或命令只复用 leaf，不重置会话；返回开启页只能通过显式“新建任务”。

原右侧 `ItemView` 原位演进为“任务环境”：默认关闭、显式开启、重复开启复用同一右侧 leaf。中央会话在它关闭时仍完整可用。

## 决策

### 当前会话投影

`NewTaskConversationController` 增加只读 `session` 投影：首条任务生成确定性标题，并冻结模式、规范工作区身份与最近一次成功校验的只读笔记标签。消息、工具与逐轮结果继续由同一个插件级控制器拥有。

- 投影只存在于当前插件生命周期；关闭并重开 Workbench leaf 会重新订阅并恢复正式页。
- 插件重载后投影清空，不显示“最近任务”，不宣称跨重启恢复。
- DSH 原生 `$DSH_HOME` 仍是完整 session、设置、凭据、模型与预设的唯一事实源；插件不建立第二套会话数据库。
- 正式会话中模式与规范工作区被锁定。若输入与当前 session 不一致，控制器以 `session_mode_locked` 或 `session_workspace_locked` 失败，不静默启动第二个 DSH session。

### 显式新建任务

“新建任务”只在没有活动 turn 时可用。确认窗口明确说明：将清除当前插件内投影并返回开启页，但不会删除 DSH 原生 session 或 Vault 外逐轮账本，也不提供跨重启最近会话恢复。控制器先关闭受管运行时，成功后才原子清空消息、权限、工具、逐轮结果与 session 投影；关闭失败时保留当前页并显示失败。

### 正式会话 UI

- 开启页主标题与正式页会话标题互斥；任一时刻只有一个 composer。
- 正式页头只显示可证明的标题、状态、模式和工作区名称/权限摘要，不显示完整绝对路径。
- 消息区域使用 `aria-live="polite"`，所有活动阶段同步 `aria-busy="true"`。
- 正式 composer 为三行紧凑初始高度，允许用户垂直增长；活动 turn 的主按钮仍为“停止”。
- UI 不显示 DSH 私有推理、未经协议读回的 token/速度/缓存指标、虚构历史或“完全权限”。

### 原生任务环境

沿用既有 view type 与命令 ID，避免迁移产生第二个右侧视图；产品标题与命令文案改为“任务环境”。它只投影：

1. DSH 健康与当前连接状态。
2. 当前会话最近一次已发送的只读笔记标签；尚未发送时显示开启页的真实选择摘要。
3. 外部工作区名称，不显示绝对路径。
4. 当前产品权限或待决定的真实工具名称。
5. “由 DSH 配置管理；当前协议未公开具体标识”的模型/预设真值。
6. 当前会话实际观察到的工具名称与最近一轮账本变更统计。

右侧栏不复制主消息流，不承载唯一权限确认、停止、审核或撤销操作；关闭时移除控制器订阅。

## 运行数据与边界

本批不新增持久文件、配置字段、依赖、bridge 事件或网络端点。`session.workspace.path` 只为当前进程内继续同一规范工作区而保留，不进入普通 UI、日志或 Vault。跨重启恢复、最近会话索引、模型/预设具体标识均需后续官方契约与真实读回，当前明确延期。

Vault 保持只读；任务写入仍只允许用户显式选择的单一 Vault 外工作区。任意 Shell、网络、Skill、子代理、自动安装/更新 DSH、Release、社区提交与 Ardot 修改均不在本批。
